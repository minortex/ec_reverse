# 00 总览与文档规则

目标机：Slimbook GOS07 / WUJIE 14（板 `GX4HRXL`）。
EC：ITE **IT5571**（8051 内核，带 PD 子固件）。
基线固件：`GXxHXxx_21.200`（256 KiB），changelog 记 EC `2.12.00.000`（2025-08-01）、PD `v27`。
唯一的蓝本是 Flash 里的字节；`.d52`、Ghidra 伪 C、GCU 反编译都只是线索。

## 当前结论一览

| 结论 | 章 |
|---|---|
| Flash = XMC XM25QH80，1 MiB；有效内容只有前 256 KiB，`0x40000+` 全 `FF` | 01 |
| 镜像按 4×64 KiB 分块擦/写/校验；擦除 = 16 条 `0x20`，不是 `0xD8` | 02 |
| `ifux64.efi` 无主机端验签；写入许可仍受 OTP/板级写保护未知 | 01 |
| `0xFC`+`0xAE` 不恢复 EC 应用，只有 `0xFE` 触发平台复位 | 01 |
| 主 EC = 32 KiB common + 3×32 KiB bank；文件块号 ≠ code bank | 03 |
| 主机 H2RAM 只暴露 4 KiB 四窗口，`0x800–0xBFF` 不可达；I2EC 走 `0x681–0x683` | 03 |
| 充电电压 = 基准 − 串数 × max(应力/循环/模式/辅助) 五档降额 | 04 |
| INT1 ISR 不保存 R0–R7，与主线共用 bank2 —— 确定的 ABI bug | 04 |
| EC 自带七状态容量校准，factor 单轮 ±3（≈±300 mAh），不写 Gauge | 05 |
| `0x07B9` 有完整原厂恢复链；`0x07D0` 原厂零引用 | 05 |
| 功耗 = 多来源非零候选取最小 → `0x086B/6C/6E`，直接 `ryzenadj` 会被覆盖 | 06 |
| `0x075B/0x075C` 是 raw duty，不是 RPM | 06 |

## 已撤回的结论

| 旧说法 | 现结论 | 章 |
|---|---|---|
| SBS `0x17` = CycleCount；`0x42` 提供容量因子 | `0x00–0x1C` 是厂商 byte 窗口；循环数走 OEM byte `0x43` | 05 |
| 擦除用 `0xD8` 64 K 擦 | 16×`0x20` 4 KiB | 02 |
| `0xFC` 退出后 EC 应用恢复 | 真机反证，见 01 | 01 |
| `< 0x8000` 代码不可达 | bank 重定位，见 03 | 03 |
| `0x07B9` 无跨掉电持久化 | 有原厂恢复链 | 05 |
| `0x05B9` 是老化函数的直接 gate | 真实 gate 是 `0x0497.bit0` | 04 |
| `0x075C` 是风扇 RPM | raw duty | 06 |
| 4 次擦写是重试 | 4 个 64 KiB block | 02 |

## 未闭合问题

| 问题 | 现状 | 下一步 |
|---|---|---|
| 16.6 V 的成因 | `0x0A54=0x1B` 与“旧 target 残留”两种解释并存 | 冷启动后立即连采 `0x0522/0x0A54/0x0836` |
| `0x0A54` 的生产者 | INT1 不保存 `R0–R7` 是事实；具体污染路径未证实 | 在 `D264` 前后插桩记录 `R7` |
| `0x09C7–0x09CA` 初值 | 初始化表为空，可能来自 SRAM 上电残值 | 冷启动 I2EC 连读 |
| 真机写入许可 | 静态“可刷”证据强，OTP/fuse/板级写保护未知 | 恢复手段就位后再受控 `--write` |
| 冷断电后 `0x07D0` | v2.2 只做了寄存器级验证 | 关整机、断电池后复测 `0x0773/0x07D0` |
| PD 固件内部 | 只确认独立向量与身份串 | 独立反汇编 `0x20000–0x3FFFF` |

## 维护规则

1. **结论进章，证据进 `_archive/`**：章节只写可复算的结论；新的调查快照不改章节正文，先落 `_archive/`，结论变化时再改章节。
2. **地址写法**：`bankN:0xXXXX` 是 bank 内逻辑地址；裸 `0xNNNNN` 是全镜像文件偏移；`main-bank1.bin` 之类别名只是 64 KiB 文件块，不是 code bank。
3. **证据门槛**：D1 及以上必须能从原始 opcode / PE 控制流 / 可复现命令复算。`.d52` 的 `jump_xxxx`、函数边界、`dptr_NNNN` 一律不能作为依据。
4. **一条结论只写一次**：跨章需要时用链接，不复制数值。
5. **改名/移动**：章节编号固定，新增主题追加新编号；`_archive/` 只进不出。
6. **硬件动作**：仓库内禁止私自执行 `ec-flash`（会禁用键盘，失联约 3 分钟可能断电）。
